# Promotion_and_Campaign_Analysis
This project analyzes store, product, campaign, and promotion data to evaluate the effectiveness of different promotional campaigns. The analysis focuses on identifying data-quality issues, understanding sales performance, and measuring the impact of promotions using key business metrics such as Incremental Revenue Percentage (IR%) and Incremental Sold Units Percentage (ISU%).

The insights generated can help the Operations, Sales, and Marketing teams make data-driven decisions about campaigns and promotional strategies.

**Problem Statement**

The retail company runs multiple promotional campaigns such as Diwali and Sankranti across different cities, stores, products, and promotion types. The operations and sales teams want to understand how these promotional campaigns are affecting sales volume and revenue and identify areas where promotional strategies can be improved.

**Task List**

Task 1: Data Cleaning – Remove Duplicate Records
Task 2: Analyze Store Distribution by City
Task 3: Handle Missing Values
Task 4: Identify Lowest Product Category Price
Task 5: Analyze BOGOF Promotion During Diwali
Task 6: Identify Highest-Selling Store During Diwali
Task 7: Compare Diwali and Sankranti Campaigns
Task 8: Calculate Incremental Revenue Percentage (IR%)
Task 9: Calculate Incremental Sold Units Percentage (ISU%)
Task 10: Identify Poor-Performing Promotion Types
Task 11: Generate Business Insights
