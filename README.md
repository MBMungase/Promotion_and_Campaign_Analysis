# Promotion_and_Campaign_Analysis
This project analyzes store, product, campaign, and promotion data to evaluate the effectiveness of different promotional campaigns. The analysis focuses on identifying data-quality issues, understanding sales performance, and measuring the impact of promotions using key business metrics such as Incremental Revenue Percentage (IR%) and Incremental Sold Units Percentage (ISU%).

The insights generated can help the Operations, Sales, and Marketing teams make data-driven decisions about campaigns and promotional strategies.
